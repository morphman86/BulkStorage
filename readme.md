# BulkStorage

BulkStorage is a Project Zomboid mod that expands storage management by adding larger, more efficient containers for your base. It focuses on improving the way players store and organize items in the game, making long-term survival and base building easier.

## About
This mod is intended for players who want better logistics and storage solutions without changing the core gameplay. It enhances base logistics by offering a straightforward way to store more items in fewer, slightly lighter containers.

- Adds bulk storage containers designed for large quantities of common supplies.
    - Including carton recipes for the boxes that currently has none in Vanilla.
- Optimizes item organization and retrieval inside storage units.
- Fits naturally into both the vanilla and modded experience.
- These bulk containers are not furniture in themselves, they are designed to stack neatly in other storage furniture.

## Current features

- Canned food cartons
    - 12 boxes of food cans fit into one carton, similar to cartons of nails or ammo.
    - Reduces the weight by 33%, like the nails and ammo cartons do.

## Planned features

- Cartons for all remaining boxable items
- Boxes and cartons for other common materials
- Crates, an even larger storage container that can fit several Cartons
- Themed containers for other bulk-storable items, such as binders for papers or wrappers for meat
